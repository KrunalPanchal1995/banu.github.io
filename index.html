How this course works

1 · Read

Each unit has a short web lesson and a full PDF (15-20 pages) with derivations, worked numbers and exercises.

2 · Play

The playground has one widget per big idea. Every slider has a plain label, a range and a help line, plus presets and a Reset button.

3 · Run

Every figure in every PDF comes from a script you can download and run. The core code uses only NumPy.

4 · Check

Click-to-reveal questions at the end of every lesson; graded exercises with answers in the PDF.
