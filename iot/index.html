Internet of Things and Robotics: a crash course

From volts and sensors to MQTT, security, kinematics, control, localisation and navigation, built around one running project: a Smart Greenhouse Rover. Twelve units with a PDF and runnable code each, a 14-lab track and an assessment bank. Built for a B.Tech student; simulation-first, no hardware needed.

The running project

The Smart Greenhouse Rover. A small differential-drive robot patrols a greenhouse, reads soil-moisture and temperature sensors, publishes them over MQTT to a dashboard and plans a path to plants that need water. Each unit adds one layer: requirements, power budget, sensing chain, node firmware, communication, dashboard, security, motion model, control, localisation, navigation, and finally an end-to-end test.

How this course works

1 · Read

Each unit is a web lesson (generated from the same source as its 15-20 page PDF) with derivations, worked numbers and exercises.

2 · Run

Every figure and every number comes from a script you can download and run; each unit's code zip includes the printed output of all of them.

3 · Be sceptical

Assumed numbers are labelled as assumed; firmware that was not run on hardware says so; external checks (paho-mqtt, cbor2, the MQTT and Mirai texts) are reported with what disagreed.

4 · Check

Every unit ends with graded exercises, a recall quiz with answers and a list of things to re-derive by hand.
