# Internet of Things and Robotics: a crash course

From volts and sensors to MQTT, security, kinematics, control, localisation and navigation, built around one running project: a Smart Greenhouse Rover. Twelve units with a PDF and runnable code each, a 14-lab track and an assessment bank. Built for a B.Tech student; simulation-first, no hardware needed.

Generated by `site_build.py` of the course knowledge base into the `iot/` subfolder of this site. Reuses the parent site's CSS and KaTeX; serve the repository root with any static web server.
